# Gestion des étudiants
## Description
Application Python permettant de calculer la moyenne et le résultat des étudiants.
## Technologies utilisées
- Python 3
- Pytest
- Git
- GitHub
## Installation
git clone https://github.com/Abdelmoiz7/gestion_etudiants.git
cd gestion_etudiants
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
## Exécution
python src/main.py
## Tests
python -m pytest -v
